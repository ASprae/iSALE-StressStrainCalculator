# iSALE-StressStrainCalculator
These python script can be used to post-process jdata.dat files from iSALE shock physics simulations.

The purpose of these scripts is to describe the history of stress and strain experienced by Lagrangian pseudocells throughout an impact event.

The first script can be used to identify the tracers you are interested in.
The second script will determine the stress-strain information of those tracers.
The third script demonstrates how the final data can be visualised.
